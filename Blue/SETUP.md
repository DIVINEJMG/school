# Blue Setup

This folder contains setup documentation and a small helper script.

## Prerequisites

- Python 3.8 or newer
- Git

## Setup Steps

1. Clone the repository:
   ```
   git clone https://github.com/DIVINEJMG/school.git
   cd school
   ```
2. (Optional) Create and activate a virtual environment:
   ```
   python -m venv .venv
   source .venv/bin/activate
   ```
3. Run the helper script to check your environment:
   ```
   python Blue/setup_helper.py
   ```

## Helper Script

`setup_helper.py` verifies the Python version and prints basic environment information.
