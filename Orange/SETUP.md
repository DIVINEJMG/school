# Orange Setup

This folder contains setup documentation and a small helper script.

## Prerequisites

- Python 3.8 or newer
- Git

## Setup Steps

1. Clone the repository:
   ```
   git clone https://github.com/DIVINEJMG/school.git
   cd school/Orange
   ```
2. (Optional) Create and activate a virtual environment:
   ```
   python -m venv .venv
   source .venv/bin/activate
   ```
3. Run the helper script to verify your environment:
   ```
   python setup_helper.py
   ```

## Helper Script

`setup_helper.py` prints a confirmation message and checks Python version.
